# Business Sales Analytics Dashboard

A complete sales analytics project built using Python, MySQL, and Power BI to analyze business sales, profit, products, categories, and regional performance.

## 📊 Dashboard

The Power BI dashboard provides an interactive view of:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales Trend
- Sales by Category
- Profit by Region
- Top Products by Sales
- Region and Category filters

## 🛠️ Technologies Used

- Python
- Pandas
- MySQL
- SQL
- Power BI
- Excel/CSV

## 🔍 Analysis Performed

### Python
Used Python and Pandas for data cleaning, exploration, and initial analysis.

### MySQL
Used SQL queries to analyze:
- Total sales and profit
- Category performance
- Regional profit
- Product sales
- Monthly sales trends

### Power BI
Created an interactive dashboard with:
- KPI cards
- Charts
- Slicers
- Profit margin analysis
- Monthly trends
