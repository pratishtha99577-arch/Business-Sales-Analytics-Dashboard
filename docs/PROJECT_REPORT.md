# Business Sales Analytics Dashboard
## Objective
Analyze business sales data to identify revenue trends, profitable categories and regions, product performance, customer behavior, and discount impact.
## Tools
Python, Pandas, Matplotlib, SQL/MySQL, Power BI
## Workflow
Raw Data → Cleaning → EDA → SQL Analysis → Power BI Dashboard → Business Insights
## Data Preparation
The raw dataset intentionally contains a few missing customer-type values and duplicate records. The cleaning script detects these issues, removes duplicates, fills missing values, converts dates, and creates Month, Year and Profit_Margin fields.
## Portfolio Value
This project demonstrates practical data cleaning, exploratory analysis, SQL querying, KPI design, dashboard development and business insight generation.
